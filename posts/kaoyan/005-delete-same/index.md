#简单 #线性表 #顺序表 #删除 

## 题目信息

> 从有序顺序表中删除所有其值重复的元素，使表中所有元素的值均不相同。

## 算法思想

由于是有序顺序表，值相同的元素一定在连续的位置上，用类似于直接插入排序的思想，初始时将第一个元素视为非重复元素的有序表。之后依次判断后面的元素是否为前面非重复有序表的最后一个元素相同，若相同，则继续向后判断，若不同，则插入前面的非重复有序表的最后，直至判断到表尾为止。

## 代码实现

```cpp
bool Delete_Same(SeqList& L) {
	if (L.length == 0) return false;
	int i, j;
	for (i = 0, j= 1; j < L.length; j++) {
		if (L.data[i] != L.data[j]) {
			L.data[++i] = L.data[j];
		}
	} 
	L.length = i + 1;
	return true;
}
```

## 复杂度分析

- **时间复杂度**：`O(n)`，其中 `n` 为原表长度，只需一次线性扫描。
- **空间复杂度**：`O(1)`，仅使用常数个辅助变量，原地修改。

# 扩展

## 题目信息

> 从有序顺序表中删除所有其值重复的元素，使表中所有元素的值均不相同。

## 解法一：暴力解

### 算法思想

采用“**前方查重，覆盖保留**”的策略。  
设变量 `i` 指向已处理的不重复序列的末端（即下一个待写入位置）。遍历原表，对于当前扫描到的元素 `L.data[j]`，在已保留的区间 `[0, i-1]` 中顺序查找是否存在相同值。

- 若**不存在**，说明该元素首次出现，将其存入 `L.data[i]` 并令 `i++`；
- 若**存在**，直接跳过。  
    由于 `i <= j` 恒成立（保留区一定在扫描区之前或重合），原地覆盖不会丢失未扫描的有效数据。

### 代码实现

```cpp
bool Delete_Same(SeqList& L) {
    if (L.length == 0) return false;
    
    int i, j, k;
    for (i = 0, j = 0; j < L.length; j++) {
        int found = 0;                     // 标记是否查重成功
        for (k = 0; k < i; k++) {          // 在已保留的序列中查找
            if (L.data[k] == L.data[j]) {
                found = 1;
                break;
            }
        }
        if (!found) {                      // 未出现过，保留该元素
            L.data[i++] = L.data[j];
        }
    }
    L.length = i;                          // 更新表长为不重复元素个数
    return true;
}
```

### 复杂度分析

- **时间复杂度**：外层循环 `n` 次，内层顺序查找最长 `i` 次（平均 `n/2`），总比较次数约为 `1+2+...+n = n(n-1)/2`，故为 **O(n²)**。
- **空间复杂度**：仅使用了常数个辅助变量（`i, j, k, found`），故为 **O(1)**。

## 解法二：哈希表 + 单次扫描

### 算法思想

在暴力解中，时间开销主要来自内层的顺序查找。若引入 **Hash 表（散列表）** 记录已出现的元素值，则可将查找时间复杂度降为 `O(1)`。  
依然采用“覆盖保留”框架：遍历原表，对于 `L.data[j]`，在哈希表中查询该值是否已记录。

- 若未记录，则将其存入保留区 `L.data[i]`，同时将该值插入哈希表，`i++`；
- 若已记录，直接跳过。  
    最终表长更新为 `i`。此算法**稳定**保持了每个元素第一次出现的相对顺序。

### 代码实现

```cpp
bool Delete_Same(SeqList& L) {
    if (L.length == 0) return false;
    
    bool hash_table[10001] = {false};      // 记录已出现的元素值
    int i = 0;                             // 指向不重复序列的末端
    
    for (int j = 0; j < L.length; j++) {
        // 查找当前元素是否已在哈希表中
        if (!hash_table[L.data[j]]) {
			hash_table[L.data[j]] = true;
		    L.data[i++] = L.data[j];
		}
    }
    L.length = i;
    return true;
}
```

### 复杂度分析

- **时间复杂度**：单层循环遍历 `n` 个元素，每次哈希查找和插入平均时间复杂度为 `O(1)`，总时间为 **O(n)**。
- **空间复杂度**：最坏情况下所有元素均不同，哈希表需存储 `n` 个元素，故为 **O(n)**。
