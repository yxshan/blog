2018真题：未出现的最小正整数

发布日期2026-08-16
中等数组原地算法置换
正文

#中等 #数组 #原地算法 #置换

题目信息

给定一个包含 nnn 个整数的数组，要求在线性时间内找出数组中没有出现的最小正整数，并且只使用常数级额外空间。

示例

A = (-5, 3, 2, 3)

正整数 111 没有出现在数组中，所以答案是 111。

A = (1, 2, 3)

正整数 111、222、333 都出现了，所以答案是 444。

直接解：逐个检查正整数

从 1 开始枚举候选答案，对每个正整数顺序扫描数组判断是否出现。第一个没有出现的数就是答案。

int findMissMinBrute(int A[], int n) {
    int candidate;

    for (candidate = 1; candidate <= n + 1; candidate++) {
        int i;
        int found = 0;

        for (i = 0; i < n; i++) {
            if (A[i] == candidate) {
                found = 1;
                break;
            }
        }
        if (!found) {
            return candidate;
        }
    }
    return n + 1;
}

时间复杂度最坏为 O(n²)，空间复杂度为 O(1)。它不修改原数组，但没有利用数组位置保存信息。

优化解：原地置换

数组长度为 nnn 时，答案一定在 111 到 n+1n+1n+1 之间。因为如果 111 到 nnn 都出现，数组中最多只有 nnn 个元素，最小缺失正整数只能是 n+1n+1n+1。

因此只需要关注数组中的 111 到 nnn。将数值 xxx 放到下标 x−1x-1x−1 的位置：

  • 数值不在 [1,n][1,n][1,n] 中时，它不会影响答案，直接跳过。
  • 数值在 [1,n][1,n][1,n] 中时，将它交换到对应位置。
  • 如果目标位置已经存放相同的数，直接跳过，避免重复数字造成死循环。

完成整理后，从左到右检查数组。第一个不满足 A[i]=i+1A[i]=i+1A[i]=i+1 的位置，对应的答案就是 i+1i+1i+1；如果所有位置都满足，则答案为 n+1n+1n+1。

示例推演

对于数组：

A = (-5, 3, 2, 3)

将数字 333 放到下标 222 的位置，将数字 222 放到下标 111 的位置，整理后可以得到：

(-5, 2, 3, 3)

检查下标 000 时，应该出现的数字是 111，但 A[0]≠1A[0]\ne 1A[0]=1，因此答案为 111。

代码实现

题目已保证 n≥1n\geq 1n≥1。下面使用数组自身作为标记空间，不引入辅助数组或标准库。

int findMissMin(int A[], int n) {
    int i, temp;

    i = 0;
    while (i < n) {
        /*
         * A[i] 在 [1,n] 内时，尝试把它放到下标 A[i]-1 的位置。
         * 目标位置已是相同数字时跳过，避免重复元素导致死循环。
         */
        if (A[i] >= 1 && A[i] <= n && A[i] != A[A[i] - 1]) {
            temp = A[i];
            A[i] = A[temp - 1];
            A[temp - 1] = temp;
        } else {
            i++;
        }
    }

    for (i = 0; i < n; i++) {
        if (A[i] != i + 1)
            return i + 1;
    }

    return n + 1;
}

正确性说明

算法结束时，所有能够放入对应位置的数字 x∈[1,n]x\in[1,n]x∈[1,n] 都被放在下标 x−1x-1x−1 处。数组中的负数、零以及大于 nnn 的数不可能成为最小缺失正整数，因此可以忽略。

从下标 000 开始检查时，如果 A[i]≠i+1A[i]\ne i+1A[i]=i+1，说明正整数 i+1i+1i+1 没有出现在数组中；由于更小的正整数都已经位于对应位置，i+1i+1i+1 就是最小缺失正整数。如果所有位置都匹配，则 111 到 nnn 全部出现，答案为 n+1n+1n+1。

复杂度分析

每个有效数字最多被交换到自己的目标位置，整理和扫描都只需要线性时间。

  • 时间复杂度：O(n)O(n)O(n)
  • 空间复杂度：O(1)O(1)O(1)

算法直接修改原数组，不使用与 nnn 成正比的额外空间。
