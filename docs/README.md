## 文档维护规则

- 架构或命令发生变化时，同一个 PR 必须同步更新对应文档。
- 当前事实写入主题文档；已失效但仍有追溯价值的内容移入 `archive/`。
- 根目录 `README.md` 只保留快速开始和文档入口，避免复制完整说明。
- 文件名使用英文小写和连字符，正文默认使用中文。
