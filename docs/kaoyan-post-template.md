## 固定格式规则

1. 年份出现在标题中并标注“真题”的文章，frontmatter 和行内标签都必须包含 `考研真题`。
2. 题图使用文章目录内的相对路径，并紧跟在“题目信息”标题后。
3. 至少提供一套直接解；存在自然优化方案时必须提供优化解，并分别写复杂度。
4. 代码优先使用 C 语言或考研常用的 C 风格写法，避免不必要的 C++ 容器和库。
5. 不改变固定标题顺序；某个章节确实不适用时，保留标题并简要说明原因。
